# 晴天娃娃桌宠

一款基于 PySide6 开发的桌面宠物程序，以可爱的晴天娃娃为视觉形象，提供丰富的桌面交互、截图工具及实用小功能，为你的桌面增添一份趣味与便捷。

## 项目介绍

本桌宠以经典晴天娃娃为呈现形象，悬浮于桌面之上，支持右键菜单触发各类功能，兼具观赏性与实用性。核心基于 PySide6 框架构建，跨 Windows 平台兼容，操作简单，界面简洁可爱。

## 功能列表

右键点击晴天娃娃形象，将弹出以下功能菜单，按需选择即可使用：

1. **动作**：晴天娃娃专属趣味动作（如晃动、眨眼、旋转等），增加桌面互动乐趣

2. **交互**：基础人机交互功能（如跟随鼠标、定点停留、互动反馈等）

3. **截图编辑**：快速截取桌面指定区域，并进入图片编辑模式（支持涂鸦、添加文字、形状标注等）

4. **编辑截屏**：加载本地截图 / 图片文件，进行二次编辑优化

5. **截图识别**：对截取或加载的图片进行文字识别（OCR），快速提取图片中的文本内容

6. **下班计时**：设置下班时间，实时显示剩余工作时长。

7. **退出程序**：关闭晴天娃娃桌宠，退出当前程序

## 运行环境

### 系统要求

- 操作系统：Windows 11（其他可自行尝试）
- 硬件：无特殊配置要求，普通办公电脑 / 家用电脑均可运行

### 依赖环境

- Python 3.11 
- PySide6 框架
- paddleocr 文字识别框架

## 快速启动（第一次运行ocr模型下载需要一点时间，报错可看后边）

### 方式 1：直接运行（已配置环境）

1. 确保你的电脑已安装对应 Python 版本，并配置好环境变量

2. 安装项目依赖：

   ```bash
   pip install -r requirements.txt
   ```

3. 下载项目源码

4. 双击 `启动main.bat`（已配置无窗口启动 + 工作目录，无需额外配置），即可启动桌宠

5. 桌面出现晴天娃娃形象后，右键点击即可调用各类功能

### 方式 2：虚拟环境启动

1. 进入项目根目录，创建并激活虚拟环境（可自行选择）：

   运行

   ```bash
   # 创建虚拟环境
   python -m venv env
   # 激活虚拟环境（Windows）
   env\Scripts\activate.bat
   ```

2. 安装依赖：

   运行

   ```bash
   pip install -r requirements.txt
   ```

3. 运行程序：

   运行

   ```bash
   python main.py
   ```

   或双击

   ```
   桌宠启动.bat
   ```

## 注意事项

1. 若运行时出现 `FileNotFoundError`，请确认 `启动main.bat` 中的项目路径配置正确，或直接将 BAT 脚本与 `main.py` 放在同一目录下
2. 桌宠默认悬浮于桌面最上层，若被其他窗口遮挡，可右键重新调用菜单或重启程序
3. 如需自定义晴天娃娃形象，可替换 `image` 文件夹下对应图片资源（建议保持图片格式与尺寸一致）

## 常见问题

1. 启动后无晴天娃娃显示？

   确认是否使用 `pythonw.exe` 启动（无控制台窗口），可通过任务管理器查看程序是否在运行，若未运行，检查 Python 路径配置是否正确

2. 截图编辑功能无法使用？

   确认已安装 `PySide6` 最新版本，或重新安装项目依赖

3. 下班计时不生效？

   检查设置的下班时间格式是否正确，确保系统时间同步准确

4. ocr模型下载失败？

   找到 虚拟环境 env/Lib/site-packages/paddlex/utils/cache.py ，不是虚拟环境找到对应python的包目录的文件即可
   修改DEFAULT_CACHE_DIR 模型下载路径
